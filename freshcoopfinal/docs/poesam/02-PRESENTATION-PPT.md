# FresCoop — Présentation Jury POESAM 2026
## 13 slides · Format 16:9 · ~8 minutes de présentation

---

## 🎨 DIRECTION ARTISTIQUE

- **Format** : 16:9 (1920×1080)
- **Fonts** : Inter Bold (titres) · Inter Regular (texte)
- **Palette** :
  - Vert foncé `#0A4B3E` — fond principal
  - Vert clair `#1F835D` — accents, icônes
  - Or `#D99912` — chiffres clés
  - Corail `#E54D35` — problème / alertes
  - Blanc `#FFFFFF` — texte sur fond sombre
  - Gris clair `#F7FBF8` — fond diapositives secondaires
- **Style** : géométrique, minimaliste, 1 idée = 1 slide, beaucoup d'espace négatif
- **Icônes** : Lucide Icons (cohérent avec l'app)
- **Photos** : agriculture sénégalaise authentique (Unsplash + Pexels avec mentions)
- **Logo** : carré arrondi 12px, gradient vert foncé → vert clair, lettre "F" blanc en 900
