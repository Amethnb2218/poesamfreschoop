Certificat d'origine numérique exportable (PDF + QR vérifiable)

Export CEDEAO / UE · Traçabilité IoT certifiée

✓ Livré

✓
Endpoint public /api/verify/lot — Vérification sans authentification, retourne les données IoT authentifiées du lot
✓
renderLotCertificateHtml() — Génère un certificat HTML/PDF avec QR scannable, données capteurs (temp, humidité), producteur, coopérative, hub, qualité, prix
✓
Boutons sur chaque lot — Télécharger certificat + Imprimer directement depuis la fiche du jumeau numérique
✓
Page /verifier étendue — Reconnaît les codes lot (FCP-DKR-XXXX) en plus des codes de reçus paiement
✓
Bande de vérification — URL et QR affichés sous chaque lot pour partage immédiat

Score de fraîcheur IA — Prédiction survie des lots

Killer feature · Algorithme ML sur données IoT + météo

🤖 Implémentable

Prédire en temps réel la durée de vie commerciale restante d'un lot en combinant : type de produit + température capteur + humidité + météo locale + historique de pertes. Résultat visible : jauge de fraîcheur colorée (vert / orange / rouge) sur chaque lot. C'est ce que Twiga Foods a fait manuellement pour passer les pertes de 30% à 4%.

Version 1 (sans ML)
  • Algorithme à règles métier : type produit × température × jours
  • Jauge fraîcheur colorée sur chaque lot
  • Seuil d'alerte configurable (3j, 5j, 7j)
  • Déployable immédiatement dans le code
Version 2 (vrai ML)
  • Modèle Python (scikit-learn / TensorFlow Lite)
  • Données d'entraînement : historique lots + météo
  • API Flask → endpoint /api/predict-freshness
  • Précision cible : ±1 jour à 85%
⚡ V1 : 2 jours de dev 🤖 V2 : 3–4 semaines 🎯 Tolbi ne le fait pas sur lots 📉 Objectif : pertes 30% → 5%
3

Micro-assurance paramétrique couplée au score économique

Score FresCoop → éligibilité assurance récolte automatique

🤝 Partenariat requis

Le score économique FresCoop (0–100) devient le critère d'éligibilité automatique à une micro-assurance récolte. Un producteur avec score ≥ 60 est pré-qualifié. En partenariat avec Pula Advisors, AXA Mansard ou un SFD local, FresCoop devient le passeport financier multi-services de l'agriculteur.

Ce que FresCoop construit (code)
  • Interface d'éligibilité basée sur le score existant
  • Simulateur de prime mensuelle estimée
  • Bouton "Demander une couverture" avec dossier pré-rempli
  • Historique des sinistres déclarés
Partenaires à cibler
  • Pula Advisors — présent au Sénégal
  • AXA Mansard / NSIA Sénégal
  • CMS Mécrédit (SFD)
  • API météo : OpenWeatherMap ou Meteomatics
🏦 Nouveau flux revenus 📋 Aucun concurrent local 👩‍🌾 +40% rétention agriculteurs 💡 Score → assurance → crédit
5

Crédits carbone agricoles — Monétisation des pertes évitées

Verra / Gold Standard · Nouvelle source de revenus pour les producteurs

🌱 Partenariat requis

FresCoop dispose déjà des données nécessaires : pertes évitées en kg, émissions de méthane réduites, nombres de lots tracés. Ces données suffisent pour calculer des crédits carbone vendables sur les marchés volontaires (Verra, Gold Standard). Chaque tonne de CO₂ évitée vaut 15–30 USD. C'est une nouvelle source de revenus pour les producteurs, financée par des entreprises qui cherchent à compenser.

Module à développer
  • Calculateur CO₂ évité par lot (kg pertes × facteur émission)
  • Tableau de bord "Impact carbone" par producteur
  • Rapport exportable pour certification Verra
  • Wallet crédits carbone (en attente partenaire)
Chiffres indicatifs
  • 1 kg nourriture évitée ≈ 2,5 kg CO₂
  • 5 000 prod × 500 kg évités = 2 500 t CO₂/an
  • À 20 USD/t = 50 000 USD/an reversés aux prod.
  • Commission FresCoop : 15–20%
🌍 RSE entreprises européennes 💵 +50 000 USD/an (cible Y3) 📊 Données déjà disponibles 🏆 Aucun concurrent en UEMOA

USSD natif renforcé — Offline-first radical

*384*FRES# · 70% des producteurs sans smartphone

📡 Accord opérateur requis

WeFarm a atteint 1 million d'agriculteurs via SMS simple. FresCoop a déjà un simulateur USSD dans l'app. Il faut maintenant signer un accord avec Orange Sénégal (ou Free / Expresso) pour déployer un vrai code *384*FRES# permettant à 100% des fonctions critiques de fonctionner sans internet ni smartphone.

Fonctions USSD prioritaires
  • Consulter le cours du marché par produit
  • Déclarer un lot (poids, produit, hub)
  • Recevoir une alerte d'expiration
  • Confirmer une vente et demander le paiement
  • Consulter son score économique
Démarches nécessaires
  • Partenariat Orange Business Services Sénégal
  • Déploiement gateway USSD (Jasmin / Kannel)
  • Backend USSD en Node.js (sessions stateful)
  • Tests terrain zones rurales : Tambacounda, Kolda
📱 Zéro smartphone requis 🌾 Zones rurales profondes 🗣️ Wolof / Pulaar / Sérère 🏆 WeFarm : 1M users via SMS
